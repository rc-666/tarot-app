# Tarot app — MVP (Android, Flutter + Supabase)

Daily 3-card tarot reading calculated from the real sky. Built 22 Nov 2026 from design handoff v2 and the decisions in the project docs (`mvp-architecture-summary.md`, `handoff-dev-review.md`).

```
app/        Flutter app (Android)
supabase/   database migrations, Edge Functions, sky engine, tests
```

## 1. Backend (Supabase)

1. Create a Supabase project (region: São Paulo, `sa-east-1`).
2. Install the Supabase CLI, then from `supabase/`:
   ```
   supabase link --project-ref <ref>
   supabase db push                      # runs the 3 migrations
   supabase functions deploy compute-sky
   supabase functions deploy delete-account
   ```
3. In the SQL editor, store the cron secrets once (not in git):
   ```sql
   select vault.create_secret('https://<ref>.supabase.co', 'project_url');
   select vault.create_secret('<service-role-key>', 'service_role_key');
   ```
4. Run the job once by hand to fill today's cards:
   `curl -X POST https://<ref>.supabase.co/functions/v1/compute-sky -H "Authorization: Bearer <service-role-key>"`
5. Auth settings (Dashboard → Authentication): email + password, **email confirmation off**, minimum password 8, redirect URL `tarotapp://auth-callback`. `supabase/config.toml` has the same values for local dev.
6. Upload the explanation library to the `library` bucket when the translation agent delivers it: `manifest.json` (`{"en": 2, "pt": 1}`) plus `<lang>.json`. The app ships with `app/assets/library/en.json` (placeholder texts) and downloads a newer version only when the manifest number goes up.

Tests: `cd supabase/functions && npm install && npm test`; SQL tests: `supabase/tests/run_sql_tests.sh` against a scratch local Postgres.

### How the cards are calculated
- **Mood** (card 1) = the Moon's decan → Minor 2–10. It follows the live sky and changes about every 18 h. `mood_shifts` holds every change for the next 8 days.
- **Influence** (card 2) = the strongest aspect from Sun…Pluto to her natal Sun (and her natal Moon, if she gave a birth time), or to her sign's midpoint before sign-up → the planet's Major. Trine/sextile = upright, square/opposition = reversed, conjunction depends on the planet. No aspect in orb → her sign's ruler.
- **Advice** (card 3) = the Moon's sign → the sign's Major.
- Cards 2 and 3 are calculated for **06:00 local time** and stay fixed for the day. The cron runs at 05:00 UTC (retry at 06:00), before 06:00 in Fernando de Noronha.
- Engine: Astronomy Engine (MIT), not Swiss Ephemeris, so there's no AGPL licence question.

## 2. App (Flutter ≥ 3.38)

```
cd app
flutter create --platforms=android --org com.example --project-name tarot_app .   # adds the Android shell; keeps lib/ and the manifest
flutter pub get            # if a version fails: flutter pub upgrade --major-versions
flutter gen-l10n
flutter analyze && flutter test
flutter run --dart-define=SUPABASE_URL=https://<ref>.supabase.co --dart-define=SUPABASE_ANON_KEY=<anon-key>
```

After `flutter create`, run `python3 tool/patch_android.py` (minSdk 24 + core library desugaring for flutter_local_notifications). Codemagic does both steps on every build.
Without `SUPABASE_URL`/`SUPABASE_ANON_KEY` (or with `--dart-define=DEMO=true`) the app runs in demo mode.
Change `com.example` to the real application id once the app name is chosen.

Optional `--dart-define`s: `POSTHOG_KEY`, `POSTHOG_HOST`, `ADMOB_BANNER_UNIT` (defaults to Google's test unit), `PRIVACY_URL`.
The AdMob **app id** in `AndroidManifest.xml` is Google's test id: replace it before release. Block the gambling, dating, loans and get-rich-quick categories in the AdMob console.

### Structure
- `lib/domain/`: card tables, models, reading assembly, notification plan (pure Dart, unit-tested in `test/`)
- `lib/data/`: Supabase repositories, offline cache, library and place search
- `lib/services/`: local notifications (2 a day), ads, analytics
- `lib/state/providers.dart`: Riverpod state; `lib/app/router.dart`: go_router routes
- `lib/ui/screens/`: onboarding 1a–1h (reused in edit mode for 6f), reading 2a/5a–5i, auth 3a–3l, home 4a–4h, settings 6a–6f

### Built with defaults from the dev review (design can replace them)
Expired reset link; 60 s resend countdown; "Deleting…"/"Couldn't delete"; offline save errors; two notification switches in Settings; "Your mood shifted at HH:MM"; mood notification copy; card ratio 1:1.72.
